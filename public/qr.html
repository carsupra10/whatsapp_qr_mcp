⚠️ Vercel Limitation

WhatsApp QR authentication cannot run on Vercel due to serverless limitations: Chrome/Puppeteer is not available, sessions are ephemeral, and there's no persistent storage.

This Vercel deployment serves as API documentation only.

💻 Option 1: Local with Claude Desktop RECOMMENDED

Best for: Personal use, full features, persistent sessions

Quick Setup:

git clone https://github.com/theaathish/whatsapp_qr_mcp.git cd whatsapp_qr_mcp npm install npm run build npm start
  1. Run the commands above
  2. Configure Claude Desktop with MCP server path
  3. Restart Claude Desktop
  4. Ask Claude: "Check my WhatsApp authentication status"
  5. Scan QR code with your phone
  6. Start messaging! ✅

💡 Why Not Vercel?

Vercel serverless functions are stateless and don't support:

  • Chrome/Chromium binaries
  • Persistent session storage
  • Long-running WebSocket connections
  • Background processes (queue system)
  • System dependencies required by Puppeteer

This Vercel deployment provides documentation and API reference, but cannot maintain WhatsApp connections.
